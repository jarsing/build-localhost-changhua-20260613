我們會體驗 LAB501 的核心流程：Skillable → Copilot CLI → Azure Skills → Starter App deployment flow。

今天的目標不是強迫每個人都完整跑完 75 分鐘官方 Lab，而是理解 AI agents 如何協助開發者準備、驗證並部署 Azure 應用程式。
